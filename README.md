# Interactive Stories

Flip-book reading stories for Grade 3 and Grade 4. Students read each page and answer questions as they go. They type their name; there is no sign-in, and answers stay on the student's device.

After **Turn In**, the student sees no score. The teacher opens the story on the student's device, clicks **Teacher**, and types the teacher code to see the score and every answer.
